# Random Color Changer 🎨

A simple Random Color Changer web project built using HTML, CSS, and JavaScript.

## 🚀 Features

- Generates a random HEX color
- Changes the background color on button click
- Displays the generated color code
- Responsive design
- Simple and beginner-friendly JavaScript project

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📸 How It Works

Click the "Change Color" button to generate a random HEX color.

Example:

#3FA82C
#FF91BD
#20A6EF
